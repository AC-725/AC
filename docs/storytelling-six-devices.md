# The six storytelling devices — portable block

The compact, paste-anywhere version of `skills/ac-studio/references/storytelling.md`
(added 2026-08-17, from the six-device frame AC flagged: hooks, emotional triggers, open
loops, curiosity gaps, pattern interrupts, pacing). ac-studio carries the full system —
register tables, per-format maps, the beat-sheet wiring. This file exists so the same
standard can be **established beyond ac-studio** without dragging the whole skill along.

## Where to install it

- **A claude.ai Project** — paste the block below into the Project's instructions (or add
  this file to Project knowledge). Every chat in that Project then writes to the standard.
- **Another skill** (pet-reviewed, ac-week, ac-revenue outreach drafts, a future format) —
  drop the block in as a reference file and add one router line: "before shipping any
  audience-facing words, run the six-device pass."
- **Another repo** — paste the block into that repo's `CLAUDE.md` under a "Writing
  standard" heading.

When a copy and ac-studio disagree, ac-studio wins — it is the single source of truth;
this block is deliberately the subset that travels.

## The block (copy from here down)

**Writing standard — the six storytelling devices.** Any audience-facing writing this
project produces (posts, scripts, slides, emails, captions) runs all six devices, then
the six-line pass at the end. The standing law over all of them: every device runs on a
real, verified fact — never on withheld information. State the surprise; never tease it.

1. **Hook.** The first line is the payoff with a stake attached, not a tease. Plain
   English, a specific number, topic clear by the end of line one, something left open
   to resolve. If the first line could open anyone's post on the subject, it's dead —
   specificity is the whole edge.

2. **Emotional trigger.** Choose the ONE feeling before writing — surprise, indignation,
   relief, awe, empathy, or trust — and produce it with facts, never claim it with
   adjectives. "14 'free' tools. 6 were trials." carries indignation with zero
   adjectives. Fear and manufactured urgency are banned registers.

3. **Open loops.** Every loop is a debt: open the main question in the first breath,
   pay it at the takeaway. Each beat ends owing the next one something — after every
   beat ask "what is still owed?"; a beat that settles its own account is a dead end.
   One small strand may deliberately outlive the piece (the question that pulls
   replies) — it stays open because it's a choice offered, never an answer withheld.

4. **Curiosity gap.** Write down the reader's default assumption, then break it with
   the verified number, then close the gap with the *why*. No writable assumption → no
   gap → no piece. Calibrate the width: too narrow bores, too wide reads as hype — an
   unbelievable-but-true number needs its named source in the same breath.

5. **Pattern interrupt.** Exactly ONE structural break, placed mid-piece where
   attention sags: the one-word beat after two dense ones, the chart after the prose,
   the turn slide. Two interrupts is noise. (At the feed/series level: the brand look
   itself is the standing interrupt — protect its consistency, and rotate formats so
   the week doesn't blur.)

6. **Pacing.** Fastest at the open, slowest at the takeaway — the densest fact lands
   early and the rule gets room. One point per beat; line break every 1–2 sentences in
   captions and emails; read it aloud, and anywhere you need a second breath inside one
   beat, split or cut.

**The pass (before anything ships):** six devices, one honest line each — hook graded,
feeling named and produced, loops opened and paid, assumption written and broken, one
interrupt placed, pacing decelerating into the rule. A line you have to talk your way
through is a fail, and a fail means fix the story, not the wording.
