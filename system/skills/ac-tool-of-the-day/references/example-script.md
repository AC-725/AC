# AC — Tool of the Day · Canva Code 2.0 — REEL SCRIPT v2 (animated + sound design)

**Runtime:** ~31s · **Format:** 1080×1920, 30fps · **Sound:** synced SFX + subtle ambient bed (baked in)
**Style:** black + gold, Lora headlines / Poppins labels · pattern-interrupt every scene, motion every ~0.3–1s

> On-screen text is what the viewer reads. VO is optional — the reel works silent-captioned, but the SFX are timed to the animation so it sings with sound on.

---

### SCENE A — HOOK + MINI-DEMO · 0.0–5.0s
**On-screen:** `TOOL OF THE DAY` → then headline **"One sentence in. / A real website out."** ("real website" in gold)
**Visual/animation:** A gold prompt bar appears; a cursor types **"a booking page for my salon"** → hits Enter → a mini website card *builds itself* below (browser bar → hero block → button pop in one by one).
**VO (optional):** "You type one sentence… and Canva builds the whole thing."
**SFX:** whoosh in · typewriter clicks · enter click · 3 soft pops as blocks build · chime when the button lands · soft bass on the headline.
*Why: oversized visual pattern-interrupt + the tool's magic shown in 5s = the strongest possible open.*

### SCENE B — THE NUMBER · 5.0–9.0s
**On-screen:** giant counter **0 → 6,000,000+** · `sites built with Canva Code 2.0` · stamp **"NOW FREE"** · `even free accounts`
**Visual/animation:** number odometers up filling the screen; a globe icon draws in; a "NOW FREE" stamp slams in on an angle.
**VO:** "6 million sites already built — and this week it went free for everyone."
**SFX:** whoosh · rapid odometer ticks (accelerating) · bass impact when it lands · stamp thud.
*Why: oversized statistic = scroll-stopper #2.*

### SCENE C — WHAT YOU CAN BUILD · 9.0–12.8s
**On-screen:** `BUILD ANYTHING` · 4 icon cards: **Calculator · Quiz · Landing page · Booking form** · footer `No code. No developer. $0.`
**Visual/animation:** four gold line-icon cards pop in one after another.
**VO:** "Calculators, quizzes, landing pages, booking forms — no code."
**SFX:** whoosh · 4 sequential pops (one per card).

### SCENE D — THE MATH (bar chart) · 12.8–17.5s
**On-screen:** `THE OLD WAY vs NOW` · bars: **$2,000 / 3 weeks** (grey, tall) vs **$0 / 10 min** (gold + ✓) · caption **"Same result. None of the cost."**
**Visual/animation:** two bars grow from the baseline; the $2,000 counts up; a gold check pops on the "$0" side; a "−100%" arrow drops from old to new.
**VO:** "A developer used to cost two grand and three weeks. Now it's zero dollars and ten minutes."
**SFX:** whoosh · rising fill-swoosh as bars grow · counter ticks · impact when bars land · ding on the check. *(2s hold on the payoff.)*

### SCENE E — HOW TO USE IT (3 steps) · 17.5–24.0s
**On-screen:** `HOW TO USE IT` · 3 progress dots fill as steps land:
1. 🟡 **Open Canva → new "Canva Code" design** *(grid/plus icon)*
2. 🟡 **Describe it in plain English:** *"a mortgage calculator in my brand colours"* *(chat icon)*
3. 🟡 **Publish → share the link** *(rocket icon)*
**VO:** "Open Canva, describe your tool in plain English, then publish and share the link."
**SFX:** whoosh · click + dot-tick per step (3×).

### SCENE F — THE RULE · 24.0–27.3s
**On-screen:** **"Stop making PDFs. / Start making tools."** ("Start making tools" gold) · sub `A quiz that grabs a lead beats a flyer. Every time.`
**Visual/animation:** a grey PDF icon gets a gold slash swiped across it → a gold tool icon pops in to replace it.
**VO:** "So stop making PDFs nobody opens — start making tools people actually use."
**SFX:** whoosh · slash swipe · pop · soft bass on the headline.

### SCENE G — CTA + LOOP · 27.3–31.2s
**On-screen:** **AC** monogram (draws in) · **@itsac.ai** · `Save this — build one this week.` (save icon bounces) · `DAILY AI TRENDS · NO HYPE, NO JARGON` · faint `try it →` cursor (loops back to Scene A)
