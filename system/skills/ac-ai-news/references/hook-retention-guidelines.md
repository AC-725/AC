# AC — AI News Reel · Hook & Retention Guidelines

The whole game of a short reel is the first second and the order you reveal things.
The design and specificity on this page are already excellent, so retention is won or
lost on two decisions: **does frame one stop the scroll, and does the payoff come first
or last.** These are the rules that keep it winning every time. They are not style
preferences; each one maps to why a viewer stays or swipes.

## The five rules (in priority order)

### 1. Open loud. Frame one is never black.
The most valuable half-second in the whole video is the very first frame. A fade-from-black,
a slow count-up from zero, or a tease that hasn't resolved yet all spend that half-second
saying nothing, and the viewer swipes before the point loads. Frame one must already show
the branded canvas **and the headline**, at full strength, hard cut in. In this template
scene A is wired to be live on frame 0 (no fade-in) for exactly this reason. If you ever
add a scene at the very start, give it the same treatment.

### 2. Payoff first. Lead with the conclusion, justify with the proof.
The strongest line in the video is the takeaway (for the Microsoft reel: "You don't need to
build AI. Just use it."). Backloading it to second 8 means most viewers never reach it. Put
the thesis in scene A and spend the rest of the reel earning it with numbers. Feed-native
order is **answer, then proof** — never proof, then answer. The old order (mystery number →
vague tease → reveal at the end) is the single biggest retention leak and it is banned here.

### 3. One "moment" every ~2 seconds.
Attention flattens when every beat looks the same (centered gold text on black, over and
over). A "moment" is a visual event: a number that odometers up, a BUILD→USE toggle that
strikes through, a stamp that snaps in, a callback line. The template gives each scene one.
When you write copy, make sure each scene still has its moment — if a scene is just a
sentence with no motion, either give it a number to count or fold it into the neighbor.

### 4. Every claim carries a specific number, and numbers earn a proof anchor.
"$2.5B", "6,000", "+$1B", "130% more" are what make the promise feel real. Vague superlatives
("the most powerful", "a genius move", "a truth nobody wants to say") do no concept-specific
work and read as clickbait. Use the real figure, match the source's wording, and when you can,
back it with a named proof (a company, a study, a result). One big number per scene, no orphan
adjectives.

### 5. Close on a loop, not a cold CTA.
End by echoing the opening line ("don't build. use. →") so the last frame rhymes with the
first. It reinforces the one idea and nudges a rewatch, which the algorithm reads as strong
retention. The follow prompt lives on the same card, quiet, never as a hard sell.

## Anti-patterns (auto-flag and fix)

- **Fade / slow count from black on frame one.** Fix: hard cut, headline already up.
- **Payoff after 4 seconds.** Fix: move the thesis to scene A.
- **Vague tease as the hook** ("a truth nobody wants to say", "this changes everything").
  Fix: state the actual claim or the concrete surprising fact.
- **A scene with no moment.** Fix: add a number to count or a visual change, or merge it.
- **Two ideas fighting in one scene.** Fix: one idea per scene; split or cut.
- **Em-dash (—) anywhere on screen.** It reads as AI-written. Use a period, a comma, or a
  line break. (This is a hard rule for on-screen copy.)
- **Jargon on a cold brain.** Plain English first; a 12-year-old should follow scene A.

## The three hook styles (pick one per video)

Scene A always leads with the payoff, but there are three proven ways to phrase it. The skill
asks which one you want each run.

1. **Thesis-first** — state the contrarian conclusion, then the number proves it.
   Formula: `[Plain contrarian claim]. / [Company] just [bet/spent] [$number] proving it.`
   Example: "You don't need to build AI. / Microsoft just bet $2.5B proving it."

2. **Concrete-image** — lead with the weird, specific, visual fact, then state the shift.
   Formula: `[Company] is [surprising concrete action with a number]. / Not to [old thing]. To [new thing].`
   Example: "Microsoft is paying to drop 6,000 people inside normal businesses. / Not to build AI. To use it."

3. **Direct-callout** — name the viewer's mistake, then justify the correction with proof.
   Formula: `If you're [common mistake], stop. / [Company] just [bet $number] on [the opposite].`
   Example: "If you're trying to build your own AI, stop. / Microsoft just bet $2.5B on using it instead."

All three: no em-dash, plain English, the number is real, the claim is the payoff not a tease.

## Hook grade scale (grade the finished scene A before you ship)

Grade holistically, not by counting. The bar for shipping is **A- or better**; if scene A
grades below that, rewrite it and re-grade.

- **A+ / A** — loud frame one, payoff stated in the first line, real number as proof, zero
  ambiguity, nothing to cut.
- **A-** — strong on all of the above with one small fixable nit.
- **B** — the idea is right but it leads with a tease, or the number is vague, or frame one is soft.
- **C or below** — no clear claim in scene A, or the payoff is backloaded. Do not ship; rebuild.

## The first-frame checklist (run it on the t=0 QA frame every time)

1. Is the headline fully legible at frame 0 (not mid-fade)?
2. Is it the payoff, or a tease? (Must be the payoff.)
3. Could a stranger say what this video is about from frame 0 alone?
4. Is @itsac.ai on the frame and is there exactly one gold idea?

If any answer is no, fix scene A before rendering the full video.
