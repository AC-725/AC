# Client Profile — Intake Template

Digest all input into this structure. Anything not answerable from the input is a gap for the gap interview (or an `ASSUMED:` item if the user says to proceed).

## Required fields

Missing any of these triggers the gap interview — one question at a time.

- **Business type and size** — what they do, rough headcount, HK-registered or not (drives the TVP note)
- **Current manual workflows** — for each: who does it, hours per week spent, tools used (WhatsApp, Excel, email, paper, existing SaaS)
- **Pain points** — what actually hurts: errors, delays, lost leads, overtime, owner doing clerical work
- **Staff tech-comfort** — can the people who'd use the automation handle new tools? Resistance history?
- **Budget signals** — anything said about spend appetite, cost sensitivity, or past software purchases

## Optional fields

Capture if present; never ask unless the user volunteers or it becomes decision-relevant.

- **Client's preferred language** — reports are always bilingual; this only informs how the user talks to the client
- **Industry specifics** — regulations, seasonality, peak periods
- **Headcount by role** — admin vs sales vs management (sharpens the ROI wage benchmark)
- **Current software** — POS, accounting package, CRM, anything with an export
- **Decision-maker profile** — owner-led? family business? who signs off?
- **Urgency** — why now: staff leaving, growth, error incident
- **Competitor pressure** — anything pushing them to move

## Notes

- Mixed EN/中文 input is normal — extract facts from both without asking for translation.
- User-authored notes override transcripts on conflict; flag the conflict in the internal brief.
