# Premium grammar — the standing reference for every video (AC, 2026-08-25)

AC supplied a reference edit (a yorixedits Claude showcase, screen-recorded) with the
instruction "use this as reference to make all my future videos more premium." This file
is what that edit actually does, translated into rules this brand can keep. It BINDS
future video runs the way voice-and-caption.md binds the words.

## What the reference does, move by move

1. **Opens on almost nothing.** One small lit element on a black field. No headline, no
   chrome. The restraint IS the hook: it reads instantly as confidence.
2. **One subject at a time.** Every beat holds exactly one element - a UI card, a line of
   type, a logo. Never two ideas sharing a frame.
3. **The subject GLIDES.** Slow drift and scale, never a hard jump inside a beat.
   Between beats, hard cuts. Motion inside a shot is continuous and small; change
   between shots is total.
4. **Type arrives as a typed line** - one sentence, conversational, lowercase energy
   ("It is very fast in all these things"), then gone.
5. **Product is the picture.** The thing itself (real UI, a real screen) carries the
   video; the words only annotate it.
6. **Signs off with the logo alone** on black. Nothing else on the frame.

## The house translation (what we adopt, what we refuse)

| Reference move | House rule |
| --- | --- |
| Open on almost nothing | LEGAL, and strong - but frame one must still be LOUD (mid-motion, payoff visible by 2.3s). "Almost nothing, already moving" is the reconciliation: one element, mid-glide, on frame 0. |
| One subject per beat | ADOPTED as law. It was already implicit ("one gold idea"); the reference proves it at the level of the whole frame, not just the accent. |
| Glide inside, cut between | ADOPTED. Inside a scene: continuous drift/scale (this also feeds gate 4). Between scenes: hard cut. The engine's `cut` transition is the premium default now, not `fade` - a fade is what the reference never does. |
| Typed one-liner | ALREADY OURS - the subtitle engine. Keep captions to ONE conversational sentence per beat. |
| Product as picture | ADOPTED for TOD (mock UI already exists) and for any story with a visible subject. A reel whose every frame is typography is now the fallback, not the default. |
| Logo sign-off alone | ALREADY LAW (the mark signs). The reference confirms: the sign-off frame carries the mark and NOTHING else that competes. |
| Purple gradient glows on the ground | REFUSED. Flat #0A0A0A is brand law. Elevation is allowed on ELEMENTS (soft drop-shadow under a card), never on the ground. |
| Licensed trending audio muxed into the file | REFUSED in-file. Deliver silent or with the house SFX bed; AC attaches the trending track inside Instagram, where it is licensed. |

## The premium tells (check every draft against these five)

1. **Empty space is doing work.** If every zone of the frame is occupied, it is not
   premium, it is dense. The bottom ~620px stays black (app chrome law) - treat that as
   a gift, not a constraint.
2. **Nothing arrives twice.** One entrance per element per scene. Re-animating something
   that already settled reads as cheap.
3. **Slow is a flex.** The reference's cards drift at maybe 20px/second. Speed reads as
   insecurity; the calm drift says "you will keep watching anyway."
4. **Weight over glow.** Premium contrast comes from stroke weight and scale, not from
   halos. (The narrator's two-weight stroke system is the house example.)
5. **The sign-off is quiet.** No CTA shouting on the last frame: mark, handle, one soft
   line. The reference ends on a logo and silence.
