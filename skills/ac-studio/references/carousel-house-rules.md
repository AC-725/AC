# House rules — @itsac.ai carousels in this project

## Interview before every carousel (ask_user, one form)
Always ask, even if the brief looks complete:
1. Theme: base / crest / column / margin
2. Which icon per slide (from the approved pack in `assets/icons/`; show the map, let AC remap)
3. Figure on/off per slide (the AC akimbo figure at `assets/ac-figure-akimbo.png`)
4. Which slide is the save/screenshot slide
5. Accent colour for the hero number(s). Default gold; AC has approved red pairs (#E5484D bright, #A32328 deep) for contrasting two counts
6. The comment keyword for the close
Then show a 50% stills board (`*- Stills Board.dc.html`) and stop. Nothing renders full-size until AC approves the board.

## Icon pack
Approved 3D pack (gold wireframe, particle fill) lives in `assets/icons/` (cropped from AC's approval board; soft at >250px). Bench bakes (dark body, gold rim) are in `bake/`. The close slide always takes the diamond mark. Never draw new icons in SVG; ask AC or bake.

## Learn every session
Read `ac-studio SKILL UPDATE 2026-09-12.md` before touching any carousel. It holds the full component vocabulary (frame, spine, footnote, hero numbers, headline, body, checklist cards, ink-on-gold, save bookmark, figure, icons) and the layout gate.

## Polish defaults (AC approved 12 Sep 2026)
- Spine with 7 nodes on every slide, filled to the current slide
- Source footnote line (10px, #5E522C) on every slide, not just the source slides
- Checklist rows as lifted #141414 cards with hairline border
- One ink-on-gold slide per deck (the rule slide by default)
- Save bookmark outline (2px gold) on the close only
- Headlines ≤ 3 lines at board scale; body copy never under the figure (right ≥ 210px at 50%)
