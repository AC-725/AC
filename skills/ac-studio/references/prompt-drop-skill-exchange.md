# Prompt Drop v5 — the skill as the exchange

When: the pack's lesson generalises (a *method*, not five recipes). Signal: AC says "for
people who are very interested" or "something more special".

Shape (7): 01 intro (question hook, 3 icons across the bottom, WORKS IN strip) · 02 rule
(ink on gold, 4 lines, 4th gold, capstone icon .85) · 03–05 prompts ("You are X. Input.
Output shape. Done line.", card 920 wide box-sizing border-box, anchor 208px lower-right,
YOU GET BACK ≤2 lines) · 06 the skill (headline = desire, body = what it does in ≤40
words, WHAT YOU GET = the real files, dim credit) · 07 close (question, COMMENT KEYWORD,
action four-up, figure, diamond).

Order prompts easiest-win first unless AC says money-first.

Skill hand-off: agent drafts `.md` (interview length AC's call, 5 default; fixed card
anatomy; `[FILL IN]` never invented; Done line closes the loop). AC rewrites; his pack is
final. Zip carries `skill/` verbatim plus a posting note naming which file goes to whom.

Bake: wireframe when a reference sheet says so; otherwise polished per 9 Sep. Board at true
size, hero spans 2 columns, capstone shown on gold. Approve before any full-size render.

Export: unwrap the stills board → full pack → snapshot 1x per label → Story cover DC →
zip {slides, skill, caption+DM, posting note, assets, notes}.
